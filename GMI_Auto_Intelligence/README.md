# GMI Global Macro Intelligence — 전 세계 국가·지역 확장판

사용자가 참고한 CFR 스타일(검은 사이드바 + 인터랙티브 세계지도)을 기반으로 한 거시경제·지정학 연구용 시연/개발 프로젝트입니다.

## 바로 실행하기

### 1) 한 파일 데모 (가장 쉬움)
`GMI_Standalone_Demo.html`을 Chrome에서 열면 설치 없이 지도, 국가 검색, 국가별 상세 패널, 등록/관리 기능이 작동합니다.

### 2) 서버 실행 (뉴스 프록시 사용)
Windows: ZIP 압축 해제 → `start_windows.bat` 더블클릭 → Chrome에서 `http://localhost:8765` 접속.
Python 3가 필요합니다. 명령창을 닫으면 서버가 종료됩니다. 기존 서버가 켜져 있으면 Ctrl+C로 종료한 뒤 새 폴더에서 재시작하세요.

macOS/Linux: `python3 server.py` 실행.

## 이번 업데이트 핵심

- 국가·지역 디렉터리: **ISO 3166-1 249개 + 코소보 연구 단위 1개 = 250개** 등록.
- 세계지도 윤곽 약 177개 (일부 중복·특수 지역 포함)와 저해상도 지도에 없는 작은 섬·국가의 위치 표시용 마커 제공.
- 지도의 좌측 `국가·지역 검색`에서 한국어, 영문 국가명, ISO2/ISO3 검색 가능.
- 상단 `국가 목록`에서 250개 항목 목록 탐색, 지역별 필터 및 검색.
- 미얀마 등 기존 상세 화면 미지원 국가도 금융시장·거시경제·외교·국방·통상·뉴스 탭 제공.
- World Bank 지표 요청을 모든 국가·지역으로 확장. World Bank에 값이 없는 국가는 없는 그대로 표시.
- 뉴스 서버의 지원 국가 범위도 250개로 확장. 기사 검색이 정확한 사건 검증을 의미하지는 않음.
- 외교 일정의 출발·도착 국가 선택 목록을 250개로 확대.
- 국가 검색 결과를 클릭하면 지도에서 위치를 찾아 상세 패널 오픈.

## 데이터의 중요 제한

1. **목록 250개는 실시간 데이터 제공 250개를 의미하지 않습니다.** 국가/지역 명칭, 국가코드, 통화 등 메타데이터와 탐색 화면의 통합 지원을 뜻합니다. 중앙은행과 지수명은 수작업 검증된 대상만 채워두었고 미등록 국가는 공란/확인 필요로 표시됩니다.
2. 실제 경제지표는 World Bank API가 제공하는 값만 불러옵니다. 인터넷이 끊기거나 통계가 존재하지 않으면 ‘데이터 없음’이 표시됩니다. 값이 실시간 시세를 의미하지 않습니다.
3. `GMI_Standalone_Demo.html`에서 뉴스 탭은 로컬 서버 API 없이 직접 열면 작동하지 않습니다. 뉴스 검색은 Python 서버 실행과 GDELT API 연결이 필요합니다.
4. 외교 방문 일정 자동 검색·검증 기능은 아직 구현되지 않았습니다. 사용자가 출처와 일정을 등록하는 기능만 제공합니다.
5. 지도 기본 24건 사건·상태는 데모이며 실시간 지정학적 위험 평가가 아닙니다.
6. 지도 경계가 표시되지 않는 초소형 영토와 다수의 섬은 근사 위치의 점으로 나타납니다. 미국령 해외 제도처럼 여러 지역에 흩어진 항목은 국가 목록에서만 접근합니다. 국경/정치적 지위 표시는 지도 자료·ISO 관행에 기반하며 국제적 주장을 판정하지 않습니다.
7. 개별 실시간 주가지수 가격, 채권금리, 공식 방문 일정 자동 수집, 국방/통상 데이터 일괄 수집은 별도 데이터 소스 연동이 필요합니다.

## 기존 데이터 보존

같은 브라우저에서 같은 서버 주소 (`http://localhost:8765`)로 열면 기존 로컬 저장소에 등록된 사건 및 외교 일정이 보통 유지됩니다. 단, 브라우저의 사이트 데이터 초기화 또는 `file://` 문서의 저장소 범위 변경 시 달라질 수 있으므로 가능하면 기존 버전에서 CSV로 내보내서 보관해 두세요.

## 폴더 구성

- `index.html`: 실제 국가 경계가 포함된 웹 페이지
- `GMI_Standalone_Demo.html`: CSS, 국가 디렉터리와 JS가 모두 내장된 단독 HTML
- `country-catalog.js` / `country-catalog.json`: 전체 국가 및 지역 목록
- `country-pins.html`: 작은 영토·국가의 지도 표시 마커
- `world-paths.html`: 저해상도 국가 경계 자료 (Natural Earth)
- `app.js`: 이벤트/국가/대시보드/비교/뉴스 UI
- `styles.css`: 사이트 디자인
- `server.py`: 로컬 서버 + World Bank / GDELT 프록시
- `assemble.py`: 템플릿·CSS·JS를 HTML로 다시 합치는 스크립트

외부 데이터 서비스의 라이선스, 호출 제한과 정합성·정책 검증은 별도로 검토해야 합니다.

## 새 기능: AI 기반 외교·국방·통상 자동 수집

웹사이트를 실행하면 로컬 서버가 자동 수집 작업을 시작하며 기본 **60분 간격**으로 갱신합니다.
`자동 인텔리전스` 메뉴에서 **지금 수집**, 최근 수집 내역, 수집 오류, AI 사용 여부, 관련 국가, 근거 링크를 볼 수 있습니다.

- **자동 수집**: GOV.UK 외교·국방 관련 Atom 피드, Google News RSS 기반 주제별 검색, GDELT DOC API. 연결 가능한 공개 출처에서 기사 제목·링크·날짜·일부 요약을 가져옵니다. 출처 가용성·서비스 제한에 따라 수집 건수가 0일 수 있습니다.
- **자동 분류**: 외교 / 국방·안보 / 통상, 기사 텍스트에 명시된 관련 국가를 ISO3 코드에 연결합니다. 국내 외교부 피드 등 다른 정부 자료는 추후 확장할 수 있습니다.
- **중복 제거/보존**: 제목+보도일 지문과 기사 URL 기반 중복 방지, 로컬 SQLite(`gmi_intelligence.sqlite3`)에 수집 데이터 보존, 180일 기본 보존 기간.
- **지도/국가 상세**: 자동 저장된 보도를 지도 마커 및 국가별 관련 이슈로 제공합니다. 모든 자동 이벤트의 상태는 **추적 중**으로 표시됩니다. 악화·개선 자동 확정은 하지 않습니다.
- **자동 갱신 조건**: Windows 서버 창이 열려 있는 동안만 주기적으로 수집합니다. 컴퓨터가 꺼져 있어도 자동 수집하려면 별도 상시 가동 서버에 배포해야 합니다.

### AI 분류 사용 설정

기본으로 뉴스 자동 수집과 **규칙 기반 분류**가 동작합니다. 이 자체가 생성형 AI 분류는 아닙니다.
진짜 AI 분류를 이용하려면, 서버를 실행하기 전에 서버 환경변수 `OPENAI_API_KEY`를 설정하세요.
Windows CMD에서 실행하는 예시 (그 세션에서만 적용):

```bat
set OPENAI_API_KEY=YOUR_API_KEY_HERE
cd /d "C:\\경로\\GMI_프로젝트폴더"
start_windows.bat
```

호출 모델 기본값은 `gpt-4o-mini`이며 환경변수 `GMI_AI_MODEL`로 변경할 수 있습니다. 비용과 요청량을 제한하기 위해 매 수집 주기에서 최대 **12건**을 AI에 전달하고, 나머지는 규칙 분류로 처리합니다. `GMI_AI_MAX_PER_RUN`(최대 30)으로 변경할 수 있습니다. API 키는 코드·브라우저·ZIP에 넣지 않습니다. 기사 제목·요약은 분류를 위해 해당 모델 제공자에게 전송됩니다. 비용은 API 사용량에 따라 발생합니다.

갱신 주기 예시: `set GMI_REFRESH_MINUTES=30` (최소 15분). 외부 제공처 과부하 방지를 위해 더 짧은 간격은 허용하지 않습니다.

### 중요한 제한

1. **모든 국가의 뉴스가 완전히 수집되는 것은 아닙니다.** 글로벌 검색과 일부 영어 공개 피드에 나타난 국가를 분류합니다. 각국 언어별 공식 정부 발표·정상 해외 방문 캘린더의 전수 모니터링은 별도 추가 개발이 필요합니다.
2. AI 및 규칙 기반 분류 결과는 뉴스 제목·요약을 기반으로 한 **미검증 보도 기록**입니다. 정부 사이트에서 나왔더라도 기사 수집만으로 회담 날짜나 참석자가 공식 확정되지는 않습니다.
3. **외교관 해외 방문 날짜를 자동 확정하지 않습니다.** 구체적 날짜가 기사에 없는 경우 일정을 만들어내지 않고 외교 보도로만 등록합니다. 기존 공식 방문 일정의 직접 등록 기능은 보존됩니다.
4. `GMI_Standalone_Demo.html`은 지도·검색·화면 확인용입니다. **자동 수집은 반드시 `start_windows.bat` 서버 모드로 실행해야 합니다.**
5. 오프라인 개발 환경에서는 공개 뉴스 API로의 실수집을 검증할 수 없었습니다. 서버 연동/중복 제거/샘플 뉴스 피드로 기능을 테스트했으며, 사용자의 PC 인터넷 환경에서 출처별 접근 여부를 확인해야 합니다.

새 파일 `auto_intel.py`가 수집·분류·SQLite 보관 및 백그라운드 작업을 담당합니다. SQLite는 Python에 기본 포함됩니다.
