# GMI v9 – 외교장관·거시경제 그래프 인터랙션

기존 GMI v8의 세계지도, 금융시장, 국가별 6개 거시경제 지표, 외교·정치, 3개 국어 UI 및 Railway 배포 구조를 유지합니다.

## 변경 사항

- 국가 상세 패널의 **국가 주요 지도부** 아래에 **외교장관** 카드가 추가됩니다. 인물명은 가능한 경우 한국어/영어/중국어 자료를 우선 사용합니다. 별도 `GET /api/foreign-minister?country=TCD` API를 추가했습니다.
- 차드의 Ahmat Kogri는 2026년 9월 임명·취임 기록과 차드 외교부의 공식 소개를 기반으로 2026-10-14 기준 스냅샷을 우선 표시합니다. 외교부 페이지는 `Ahmed KOGRI`라는 표기도 사용합니다. 출처: https://diplomatie.td/ . 2026-09-22 취임 보도: https://portail.td/ahmat-kogri-prend-les-renes-du-ministere-des-affaires-etrangeres/ .
- 그 외 국가는 이미 사용 중인 정부 내각 목록(CIA World Leaders 및 검증 일자가 있는 국가 스냅샷)에서 외교 담당 장관을 찾습니다. 최초 조회 시 정부 자료 수집에 시간이 걸릴 수 있으며, **확인되지 않은 인물은 만들지 않습니다**.
- 국가 거시경제 5년 차트와 국가 간 거시경제 비교 차트에서 연도별 점에 마우스를 올리면 연도와 수치가 표시됩니다. 클릭·키보드 포커스도 지원합니다.
- 퍼센트 지표는 `%`, 경상계정·금융계정은 설정 언어에 맞춰 계산된 통화 단위를 사용합니다. 외환 API에 연결되지 않은 경우 기존 달러 표시로 돌아갑니다.

## 배포

1. 이 ZIP을 풀고 **안의 파일 자체를** GitHub 저장소 `kimhwanhee/gmi-macro-intelligence`의 최상위에 업로드합니다.
2. 기존 파일들은 동일 이름으로 덮어쓰고, 새로운 `foreign_minister_data.py`, `v9-interactions.js`, `v9-interactions.css`도 꼭 포함합니다.
3. Commit changes 후 Railway가 자동 배포합니다. `Active`인지 확인하고 브라우저에서 Ctrl+Shift+R로 새로고침합니다.
4. 차드 선택 → 외교장관 이름 확인. 국가 상세 → 거시경제 → 5년 차트의 점에 마우스를 올립니다.

## 확인 범위와 한계

로컬 Python API, 공개 정적 파일 접근 규칙, JavaScript 구문, 5개 연도 데이터 바인딩까지 검사했습니다. 이 실행 환경의 Chromium은 로컬 파일/URL 내비게이션이 관리자 정책으로 차단되어 전체 페이지 브라우저 통합 테스트는 진행하지 못했습니다. Railway 실서비스에서 UI를 다시 확인해야 합니다. World Bank와 공식 정부 자료 API의 실제 최신 응답은 배포 후 제공처에 따라 달라집니다.

정부 명단은 마지막 자료 확인일을 표시할 뿐 모든 국가의 현직 여부를 실시간 보증하지 않습니다. 실제 고위급 일정의 검증/자동 등록은 이번 패치의 범위에 포함하지 않았습니다.
