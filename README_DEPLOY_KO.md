# Global Macro Intelligence v4 — Railway 배포

기존 GitHub 저장소 `gmi-macro-intelligence`와 연결된 Railway 서비스에 업로드하는 **전체 교체용 소스**입니다. 새 서비스나 도메인을 만들 필요가 없습니다.

## 배포

1. `GMI_v4_Country_Macro_Update_Railway.zip` 압축을 풉니다.
2. 압축을 푼 폴더 **안의 파일**을 전부 선택하여 GitHub `gmi-macro-intelligence` 저장소 **최상위(root)**에 업로드합니다. ZIP 파일 자체나 하위 폴더만 업로드하지 마세요.
3. `Dockerfile`, `server.py`, `refinements.js`, `verified-officials.json`, `index.html`, `research_api.py` 등이 루트에서 보여야 합니다.
4. `Commit changes`를 누르면 GitHub와 연결된 Railway가 자동으로 배포합니다. Railway > Deployments에서 SUCCESS / Active 확인 후 사이트를 Ctrl+Shift+R로 새로고침합니다.
5. 기존 Railway의 Volume이 **/data**에 연결되어 있는지 확인하세요. 미연결 시 SQLite 뉴스/캐시가 재배포마다 사라질 수 있습니다.

## 선택적 AI 요약/번역 활성화

Railway > 서비스 > Variables에 `OPENAI_API_KEY`를 비밀 변수로 추가하세요. 이 키는 자동으로 가져온 뉴스의 **제목·요약을 한국어/영어/중국어로 구조화**하고, 다른 국가에 대한 영향을 가능한 가설로 설명하는 데 사용됩니다. API 이용료가 발생할 수 있습니다. 원문 기사 전체가 아니라 RSS 제목/발췌문 기반이므로 원문에 없는 세부 사실은 생성해서는 안 됩니다. GitHub 저장소나 브라우저 코드에 키를 넣으면 안 됩니다.

API 키가 없는 경우에도 지정된 언어로 발행된 RSS 뉴스 검색과 정기 자동 수집은 작동하도록 설계했지만, **모든 외국어 뉴스를 자동 번역하지는 못합니다.** 언론사 고유명사는 출처 확인을 위해 원문으로 남깁니다. 뉴스 수집 소스 응답·현지 기사 가용성에 따라 일부 국가·분야는 비어 있을 수 있습니다.

## 변경 사항

- 국가·지역 250개 대륙별 분류, 국기, 한국어 가나다 / 영어 알파벳 / 중국어 병음 순 정렬
- 국가 연구 패널: 금융시장 / 8개 거시경제지표의 최근 5년 추이 / 외교·안보·통상 통합 / 오늘의 뉴스
- 4개 분야(경제·정치·국방·외교) 뉴스 1~2개, 수집 중 상태, 국가 간 영향 설명(선택적 AI API)
- 지정학적 사건은 지역·분야별로 필터링, 한 번에 16개부터 표시
- 미국·중국·러시아·영국·한국: 정부 공식 자료의 **2026-10-12 기준** 주요 지도자·부처 장관 기초 명단. 다른 국가는 Wikidata 등 외부 데이터 조회. 명단은 인사 변동 시 갱신해야 하므로 실시간 검증된 데이터라고 간주하면 안 됩니다.
- TradingView 차트 1시간·4시간·일봉·주봉. 일부 지수는 임베드가 제한돼 **지수 추종 ETF를 대체 표시하며 ETF라고 명확히 표기**합니다. 모든 국가/지수의 위젯 지원을 보장할 수 없습니다. 제공되지 않는 국가에는 ‘미등록’이라고 표시됩니다.
- World Bank API 8지표 합쳐서 조회 및 6시간 서버 캐시, 뉴스 소스 병렬 갱신
- 정보 없음 대신 최초 로딩 또는 수집 중으로 표시하며, 서버 오류가 길어지면 확인 중 메시지 표시
- 주식/경제 통계는 투자 조언이 아니고 공식 발표와 시장 자료를 개별 확인해야 합니다.

## 중요한 기술적 한계

이 프로젝트는 **개인 연구용 프로토타입**입니다. 정부 공식 외교 방문 예정 전 세계 전체를 완전하게 모으는 기능은 아직 없습니다. 외교 ‘보도 추출’과 ‘공식 일정 확정’을 혼동하면 안 됩니다. 위젯의 장중 지연·라이선스·공급 제한은 TradingView와 거래소 정책에 따릅니다. 외부 서비스 접속 실패 시 데이터를 임의로 채우지 않습니다.

## 코드 안전

웹 서비스는 `GMI_PUBLIC_MODE=1`로 공개 환경에서 동작하고, 내부 Python 코드·JSON 명단·데이터베이스를 정적 URL에서 제공하지 않습니다. 관리자 수집 API는 `GMI_ADMIN_TOKEN` 환경변수를 통한 인증이 필요합니다. OpenAI 키는 Railway Variables에만 보관합니다.
